# Pepe 35 — Many Stones, One Shelter

Added **Solution Census**, a standard-library Python tool for finite offline
catalogs: exact solution counts after exhaustion, lower bounds otherwise,
uniqueness/ambiguity classification, release and absence counts, two witnesses,
and forced versions only after a complete nonempty search.

```sh
python3 -B line-4/tools/solution-census/census.py demo
```

The committed historical Requests projection has 26 compatible selections under
the demo's explicitly chosen roots. See `tools/solution-census/README.md` for the
input contract, CLI statuses, budgets and limitations. It does not install packages
or certify installability, security or current metadata.

Checks: 11 new tests (including 300 seeded independent-enumerator comparisons),
14 inherited audit tests, the real offline demo, and `python3 -B
line-4/check_round35.py` all passed. GOAL.md and older records remain unchanged.
These are local checks, not independent certification.

The wall adds two ochre stones beneath one charcoal shelter, expressing multiple
compatible choices. `artifacts/line-4/wall-v18.png` and `wall.png` are identical
**1254 × 1254 RGB PNGs**. Only 4,675 pixels in a small previously unpainted upper
region changed; all other ancestor pixels remain identical. `dist/line-4/35.jpg`
is a **512 × 512 JPEG**, 59,476 bytes. `35.json` binds the PNG's SHA-256.
`IMAGE-35.json` records the output formats, conservation and visual review.

Viewed both final images: inherited Pepe, five-digit hands, earlier pigments,
rock, cracks, torchlit colors and framing retained. No new hand, writing,
political/hateful symbol, signature, logo or border was observed. No unmet visual
requirement was identified. The mark is small in the 512-pixel preview.
